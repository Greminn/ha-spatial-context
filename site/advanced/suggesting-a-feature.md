# Suggesting a Feature

Feature ideas are welcome, and are tracked as issues on GitHub.

1. Search the [open issues](https://github.com/Greminn/ha-spatial-context/issues) first. If the idea is already there, add a thumbs-up and any detail of your own to that issue, instead of opening a new one.
2. Otherwise, [open a new issue](https://github.com/Greminn/ha-spatial-context/issues/new/choose) and choose **Feature request**.
3. Answer the questions on the form:
   - **What problem or use case is this for?** Describe what you are trying to do, or what is missing or annoying today.
   - **What would you like to see?** A rough idea of how it could work is enough.
   - **Anything you have already tried?** For example a workaround.

A screenshot of the part of the panel you mean helps. Keep to one idea per issue, so each can be discussed and tracked on its own.

::: tip
This is a personal project, so there is no promise of when, or whether, an idea is built. Describing the problem you are trying to solve helps most, because it can often be solved in a way the first suggestion did not think of.
:::
